# ИНСТРУКЦИЯ: собери APK за 15 минут (без знаний в коде)

Этот ZIP — готовый Android-проект приложения «VK Emoji Pro» (раньше VK Emoji Clicker).
Сборка происходит в облаке GitHub БЕСПЛАТНО. Тебе нужно только один раз
настроить, дальше кнопка «Run» — и APK готов.

Текущая версия: 1.6 (versionCode 7).

================================================
ЧАСТЬ 1. Зарегистрируйся на GitHub (если нет)
================================================
1. Открой https://github.com/signup
2. Заполни форму (email, пароль, имя пользователя). Подтверди email.
3. Это бесплатно, ~2 минуты.

================================================
ЧАСТЬ 2. Создай репозиторий
================================================
1. Войди на GitHub.
2. В правом верхнем углу жми «+» → «New repository».
3. Repository name: напиши например   vkemojiclicker
4. Обязательно выбери «Private» (приватный — код никто не увидит).
5. Остальное не трогай → жми зелёную кнопку «Create repository».
   Откроется страница, где будут команды — пока игнорируй, нам понадобится
   только кнопка справа вверху «uploading an existing file» (или «Add file»).

================================================
ЧАСТЬ 3. Залей файлы (САМЫЙ ВАЖНЫЙ МОМЕНТ)
================================================
ВАЖНО: заливать надо СОДЕРЖИМОЕ папки android (сам ZIP распаковывать в папку).

1. Распакуй этот ZIP в любое место, например в папку  C:\MyApp\
   (должна получиться папка со всеми файлами проекта: app, build.gradle,
    settings.gradle, .github и т.д.)

2. На странице нового репозитория жми кнопку
   «Add file» → «Upload files».

3. Открой папку проекта (куда распаковал), выдели ВСЕ файлы и папки ВНУТРИ
   (app, build.gradle, settings.gradle, gradle, .github, .gitignore...)
   и перетащи их мышкой в окно браузера на страницу загрузки.

   ВАЖНО: перетаскивай файлы ИЗНУТРИ папки проекта, а не сам архив и не саму
   папку. Должно появиться ~27 элементов.

4. Ниже жми «Commit changes» (комментарий можно оставить как есть).

Файлы загрузились. Теперь сборка запустится САМА автоматически.

================================================
ЧАСТЬ 4. Забери готовый APK
================================================
1. Подожди 10–15 минут (можно обновить страницу).
2. Вверху репозитория нажми вкладку «Actions».
3. Должен появиться список запусков (жёлтый/зелёный). Зелёная галочка = готово.
4. Жми на последний запуск → внизу секция «Artifacts» (артефакты).
5. Скачай файл «VKEmojiClicker-apk». Это архив (zip), внутри лежит
   app-debug.apk — это и есть установочник приложения.

Этот .apk отправляешь покупателям (как с ПК-версией — файлом).

================================================
КАК ПОЛЬЗОВАТЬСЯ ПРИЛОЖЕНИЕМ
================================================
1. Установи apk → открой → введи ключ лицензии → «Активировать».
2. Прикрепи фото эмодзи (кнопки «Прикрепить фото»):
   - ПРИОРИТЕТ — главный эмодзи (обязательно)
   - НЕ ПРИОРИТЕТ — запасной (можно не заполнять)
   Лучше вырезать значок без фона — приложение само обрежет белое/прозрачное.
3. Открой диалог в VK и покажи панель эмодзи (нужный эмодзи должен быть виден).
4. Настройки: чувствительность (стандарт 70), зона поиска (стандарт 58–88%),
   КД (стандарт 1.4–1.9 сек).
5. «Найти и кликнуть» — один проход (сначала приоритет, потом не приоритет).
   «Авто» — повторяет в цикле, пока не нажмёшь «Стоп».

================================================
ВЕРСИИ (ВАЖНО ДЛЯ ОБНОВЛЕНИЙ)
================================================
Каждый раз, когда меняешь код и пересобираешь APK, поднимай номер версии
в файле app/build.gradle:
    versionCode 7   -> +1 (8, 9, ...)
    versionName "1.6" -> "1.7", "1.8", ...
Иначе на телефоне останется старая версия (Android не обновит «ту же»).

================================================
ЕСЛИ СБОРКА КРАСНАЯ / ОШИБКА
================================================
1. Жми на красный запуск в Actions → увидишь лог с ошибкой.
2. Самая частая причина: файлы залиты неправильно (архив вместо содержимого,
   или папка не та). Проверь ЧАСТЬ 3.
3. Скопируй текст ошибки и пришли мне — поправлю.

================================================
ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ (честно)
================================================
- Приложение кликает только внутри своей вкладки (WebView с VK).
- VK может вести себя по-разному в WebView — нужно проверить на телефоне.
- Автоматизация VK несёт риск бана аккаунта — предупреди покупателя.
- Это debug-сборка (без подписи) — для Play Store не подходит.
