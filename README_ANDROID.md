# VK Emoji Clicker — Android сборка через облако (GitHub Actions)

Готовый Android-проект лежит в папке `android/`. APK собирается автоматически в облаке
GitHub (быстрый интернет, ~10 минут), тебе не нужно ставить Android Studio.

## Как собрать APK (пошагово)

Тебе нужен бесплатный аккаунт GitHub (github.com — Sign up).

1. **Создай пустой репозиторий** на GitHub (New repository, имя любое, напр. `vkemojiclicker`, Private — приватный, чтобы код не светился).

2. **Залей проект.** Проще всего через GitHub Desktop или команды. Папку `android/` целиком:
   - в ней и так лежат `.github/workflows/build.yml`, Gradle-файлы, `app/`.
   - НЕ заливай: папки `build`, `.gradle`, `dist`, `release` — их в `android/` нет.

   Команды (если есть git):
   ```
   cd android
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/ИМЯ_РЕПО.git
   git push -u origin main
   ```

3. **Запусти сборку.** Открой репозиторий → вкладка **Actions** → слева workflow **«Build APK»** → справа кнопка **«Run workflow»** → Run. (При первом push она запустится сама.)

4. **Скачай APK.** Через ~10–15 минут в Actions появится зелёная галочка. Жми на джобу `build` → внизу секция **Artifacts** → скачай **VKEmojiClicker-apk** (это архив, внутри `.apk`).

5. Готово. Раздаёшь `.apk` покупателям ссылкой (как с exe — файлом).

## Что делает приложение

- При запуске — окно ввода ключа (лицензия с твоего сервера 91.107.125.66:8000, тот же механизм «ключ → устройство»).
- После активации — экран со встроенным браузером (WebView), открытым на `https://vk.com/im` (диалоги VK).
- Внизу — сетка эмодзи (та же, что и в ПК-версии) + кнопки «Найти и кликнуть», «Авто», «Стоп».
- При нажатии на эмодзи приложение делает скриншот своей WebView, ищет этот эмодзи (шаблонный матчинг) и эмулирует тап по нему + рисует оверлей-курсор (куда нажимает).
- «Авто» — повторяет поиск и клик автоматически.

## Важные честные ограничения (учёл при написании)

1. **Тап только внутри своего приложения.** Кликер умеет кликать в ЭТОТ WebView (свою вкладку). На тап по системным клавиатурам и чужим приложениям ОС не даст (это платформенное ограничение).
2. **`vk.com/im` в WebView** — VK может показать мобильную версию или требовать вход. Часть логики панели эмодзи работает как на ПК не всегда — надо тестировать на реальном устройстве.
3. **Риск бана VK-аккаунта** за автоматизацию — предупреди покупателя заранее (как договорились).
4. **Это debug-сборка** (быстро, без подписи). Для Play не годится — но мы и не идём в Play.

## Если Action падает
- Открой жёлтую/красную джобу → посмотри лог на строчке с ошибкой.
- Частая причина: нет прав у `git` — тогда заливай через GitHub Desktop (не командой).
